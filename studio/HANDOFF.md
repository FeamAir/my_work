## Правило остатка

Баланс fal.ai не ниже $20, при остатке ≤ $30 — сообщить инвестору (status.md → «Правила инвестора»). Оценка остатка считается по журналу `output/costs.jsonl`, а `output/` не в git и контейнер временный — **после каждой платной сессии копировать журнал в `studio/budget/costs.jsonl` и коммитить**, а в начале новой — возвращать в `output/`. Периодически сверять с реальным балансом в кабинете fal.ai (оценки цен приблизительные).

## После подключения

проверка ключей (`python3 -m pipeline.check_services --live`) → стилевой тест на Пелл (~$3) → тест моделей (~$15–30) → эталоны (~$48) → пробы голосов/темы → аниматик (~$30) → **просмотр инвестором** → финальная генерация пилота (визуал ≈ $143, с резервом ≈ $172) → звук, сведение, QA.
