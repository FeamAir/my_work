# Кастинг голосов: шаблон карточки и примеры

> **HOLLOWSTONE (r3, 2026-11-22):** язык озвучки теперь **английский**: тестовые фразы на английском, а пункт «native Russian speaker» не применяется. Карточки пилота — `pilot_voices.md`. Порядок Voice Design и правило «без имён реальных людей» остаются в силе. Модели: см. A/B v2 / v3 / v4 в `emotion_markup.md` §6.

Версия 0.1 от 2026-11-22. Автор: звукорежиссёр.
Карточки реальных персонажей появятся после библии персонажей от сценариста (`studio/story/`). Ниже — шаблон и два примера для условных персонажей.

## Порядок кастинга (ElevenLabs Voice Design)

1. Звукорежиссёр заполняет карточку по библии персонажей.
2. Запрос `POST /v1/text-to-voice/design`:
   - `voice_description` — промпт из карточки (английский);
   - `text` — тестовая фраза на русском (**100–1000 символов**, поэтому тестовые фразы в карточках не короче 100 символов);
   - `model_id` — `eleven_multilingual_ttv_v2` (по умолчанию) или `eleven_ttv_v3` (для сравнения);
   - `guidance_scale` — начать с 5, при «пластиковом» звучании снижать до 3–4;
   - `seed` — фиксировать и записывать в карточку, чтобы результат можно было воспроизвести.
3. Сервис возвращает несколько превью. Слушаем, выбираем лучшее, при необходимости правим промпт (до 3 итераций).
4. Выбранное превью сохраняется как голос (`POST /v1/text-to-voice` с `generated_voice_id`) — в карточку записывается полученный `voice_id`.
5. Прогон «боевых» реплик (3–5 фраз с разными эмоциями) через TTS с настройками из карточки. Подбор stability/style.
6. Карточка получает статус «утверждён». После этого голос и настройки не меняются без записи в журнал изменений карточки.

Общие правила:
- **Никаких имён реальных людей** в промптах (актёров, певцов, блогеров) и формулировок «sounds like…». Только описательные характеристики.
- Голоса подростков описываем как **молодой взрослый голос, звучащий юно** (`young adult … with a youthful, teen-like sound`), а не как голос ребёнка.
- Язык: в промпте указывать `native Russian speaker, standard Russian pronunciation`, иначе модель может добавить акцент.
- Акцент персонажа (если нужен по сюжету) описывается словами, без пародии на реальные национальности в обидном ключе.
- Модель TTS одна на весь сезон. Основной кандидат: `eleven_multilingual_v2`; `eleven_v3` проверяем на эмоциональных сценах (у v3 есть аудиотеги вроде `[whispers]`, `[laughs]`, но поведение и допустимые значения настроек нужно сверить с актуальной документацией при подключении API).

### Подготовка русского текста для TTS
- Числа, даты, сокращения — словами («в две тысячи сорок пятом», а не «в 2045-м»).
- Всегда писать «ё».
- Ударения в именах и выдуманных словах — через словарь произношений (pronunciation dictionary, alias-правила: «Айра» → «Ай-ра»), а не вручную в каждой реплике.
- Паузы — знаками препинания (многоточие, тире); длинные реплики (> 250 символов) резать на фразы и генерировать раздельно.
- Эмоцию задавать контекстом реплики и настройками (stability/style), а не только восклицательными знаками.

## Шаблон карточки

```markdown
# Голос: <Имя персонажа>

| Поле | Значение |
|---|---|
| ID карточки | VOICE-<NNN> |
| Персонаж | <имя>, <роль в сюжете> |
| Ссылка на библию персонажа | studio/story/<файл>#<раздел> |
| Пол | |
| Возраст персонажа / звучание голоса | <возраст персонажа> / <на сколько звучит голос> |
| Тембр | <высота, окраска: светлый/тёмный, звонкий/бархатный/хрипловатый, «воздух» в голосе> |
| Темп речи | <медленный/средний/быстрый>; speed = <0.9–1.1> |
| Манера | <как говорит: отрывисто, певуче, с паузами, с улыбкой> |
| Эмоциональный диапазон | <базовое состояние> → <крайние точки: крик, шёпот, плач, смех> |
| Акцент / речевые особенности | <нет / описание> |
| Модель TTS | eleven_multilingual_v2 |
| Модель Voice Design | eleven_multilingual_ttv_v2 |
| voice_id | <заполняется после утверждения> |
| seed / guidance_scale | <число> / <число> |
| Статус | черновик / на тесте / утверждён |

## Промпт для Voice Design (EN)
<2–5 предложений: возраст и пол, высота и тембр, темп и манера, эмоциональная база, качество записи, язык>

## Тестовая фраза (RU, 100–1000 символов)
<текст, в котором есть спокойная часть, вопрос, эмоциональный всплеск и тихая фраза>

## Настройки TTS
| Режим | stability | similarity_boost | style | use_speaker_boost | speed |
|---|---|---|---|---|---|
| Базовый (обычная речь) | | | | true | |
| Эмоциональный (крик, слёзы, азарт) | | | | true | |
| Тихий (шёпот, интим, мысли) | | | | true | |

## Боевые фразы для проверки
1. <нейтральная>
2. <радость/азарт>
3. <страх/гнев>
4. <шёпот>

## Журнал изменений
| Дата | Что изменено | Причина |
|---|---|---|
```

### Ориентиры по настройкам (`eleven_multilingual_v2`)

| Параметр | Диапазон | Как влияет |
|---|---|---|
| `stability` | 0.30–0.65 | ниже — живее и эмоциональнее, но больше разброс между дублями; выше — ровнее, но может звучать монотонно |
| `similarity_boost` | 0.70–0.85 | насколько строго держится утверждённый тембр; выше 0.9 возможны артефакты |
| `style` | 0.0–0.35 | усиливает выразительность; выше 0.4 — риск переигрывания и нестабильности. По умолчанию держим низким |
| `use_speaker_boost` | true | чуть больше сходства с голосом |
| `speed` | 0.9–1.1 | темп; за пределами 0.85–1.15 качество заметно падает |

Для каждой реплики делаем 2–3 дубля (разный seed) и выбираем лучший — это дешевле, чем «докручивать» настройки.

## Пример 1. Подросток-героиня (условный персонаж)

| Поле | Значение |
|---|---|
| ID карточки | VOICE-EX1 (пример) |
| Персонаж | Условная героиня, 16 лет, главная роль: любопытная, упрямая, быстро загорается |
| Пол | женский |
| Возраст персонажа / звучание голоса | 16 / голос молодой взрослой (около 20), звучащий юно |
| Тембр | светлый, звонкий, средне-высокий; немного «воздуха» на концах фраз; без детской писклявости |
| Темп речи | быстрый в азарте, средний в спокойных сценах; speed = 1.05 (базово) |
| Манера | говорит на улыбке, слегка проглатывает паузы, когда волнуется; вопросительные интонации |
| Эмоциональный диапазон | бодрая, любопытная → громкий азартный крик, обида со слезами в голосе, растерянный шёпот |
| Акцент / особенности | нет, стандартное русское произношение |
| Модель TTS | eleven_multilingual_v2 |
| Модель Voice Design | eleven_multilingual_ttv_v2 |
| voice_id | — (не сгенерирован) |
| seed / guidance_scale | 1001 / 5 |
| Статус | черновик |

**Промпт для Voice Design (EN):**
```text
Young adult female voice with a bright, youthful, teen-like sound, around 18-20 years old. Clear, light mid-high pitch with a slight breathy airiness at the ends of phrases, energetic and curious, often sounds like she is smiling. Fast, lively pacing that speeds up when excited. Native Russian speaker with standard, neutral Russian pronunciation. Clean studio recording, close microphone, no background noise.
```

**Тестовая фраза (RU):**
```text
Подожди, ты это тоже видел? Там, за старой башней, что-то светится! Нет-нет, я не выдумываю, честное слово. Пойдём посмотрим, ну пожалуйста! ...Ладно. Если ты боишься, я схожу сама. Только никому не говори, хорошо?
```

**Настройки TTS:**

| Режим | stability | similarity_boost | style | use_speaker_boost | speed |
|---|---|---|---|---|---|
| Базовый | 0.45 | 0.80 | 0.15 | true | 1.05 |
| Эмоциональный | 0.32 | 0.78 | 0.30 | true | 1.08 |
| Тихий | 0.55 | 0.80 | 0.05 | true | 0.95 |

**Боевые фразы:**
1. «Доброе утро! Я опять проспала, да?»
2. «Получилось! У нас правда получилось!»
3. «Отпусти его! Слышишь? Немедленно отпусти!»
4. «Тише... кажется, он нас не заметил.»

**Промпт для Voice Design (EN):**
```text
Elderly male voice, around 70 years old. Low, warm, velvety baritone with a slight natural rasp and gentle breathiness. Slow, measured, calm delivery with thoughtful pauses, quietly confident and kind, with a hint of dry humor. Native Russian speaker with standard Russian pronunciation, slightly drawn-out vowels at the ends of phrases. Clean studio recording, close microphone, no background noise.
```

**Тестовая фраза (RU):**
```text
Не торопись. Сила — это не то, как громко ты кричишь, а то, сколько ты можешь выдержать молча. Я тоже когда-то бежал впереди всех... и потерял слишком много. Садись. Чай остынет, а разговор у нас будет долгий.
```

**Настройки TTS:**

| Режим | stability | similarity_boost | style | use_speaker_boost | speed |

| Эмоциональный | 0.45 | 0.80 | 0.25 | true | 0.95 |
| Тихий | 0.65 | 0.82 | 0.05 | true | 0.88 |

**Боевые фразы:**
1. «Ну что, ученица, опять опоздала?»
2. «Хм... неплохо. Очень даже неплохо.»
3. «Стой! Ни шагу дальше!»
4. «Когда-нибудь ты поймёшь. Но не сегодня.»
