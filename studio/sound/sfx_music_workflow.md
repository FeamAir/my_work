# SFX и музыка: от сценария к списку генерации

Версия 0.1 от 2026-11-22. Автор: звукорежиссёр.
Входные данные: сценарий серии (`studio/story/`) и шот-лист режиссёра-постановщика (`studio/direction/`). Выход: таблица звуков серии `studio/sound/epNN_sound_table.md`, по которой IT-конвейер вызывает ElevenLabs.

## 1. Процесс («споттинг»)

1. **Получить хронометраж.** Берём шот-лист: номер сцены, номер кадра, длительность кадра, место, время суток, действие, реплики. Таймкоды считаем от начала серии (`ММ:СС.мс`). Если шот-листа ещё нет — работаем по сценарию с оценочными длительностями (≈ 15 символов реплики в секунду для спокойной речи) и помечаем строки `TC≈`.
2. **Локации → эмбиент.** Для каждой локации серии — эмбиент-карточка (раздел 4). Если карточка уже есть в библиотеке — переиспользуем.
3. **Пройти сценарий построчно** и выписать каждый звук по ключевым словам-триггерам:

| Что ищем в тексте/шот-листе | Тип звука | Пример |
|---|---|---|
| Место, погода, время суток, толпа | AMB | «ночной рынок», «дождь», «пустой класс» |
| Действие с ударом/контактом: дверь, падение, удар, взрыв | HARD (жёсткий SFX) | «захлопывает дверь» |
| Движение тела и предметов: шаги, одежда, ложка, бумага | FOLEY | «идёт по коридору», «листает книгу» |
| Нереальные явления: магия, технологии, интерфейсы, трансформации, «аниме-свисты» | DES (дизайн) | «вспыхивает печать», «мгновенный рывок» |
| Смена настроения, вход/выход сцены, кульминация | MUS (трек) | «напряжение нарастает» |
| Резкий акцент, шутка, разоблачение, переход между сценами | STING | «она оборачивается — это он!» |
| Голос без слов: вздох, смех, крик толпы | VOX (через TTS или SFX) | «толпа ахает» |

4. **Сначала библиотека, потом генерация.** Каждый звук проверяем по манифесту библиотеки (`studio/sound/library/manifest.md`, будет создан с первой серией). Повторяющиеся звуки (шаги героини, дверь её комнаты, «фирменный» свист перехода) генерируются один раз.
5. **Заполнить таблицу** (раздел 2) и пометить статус.
6. **Генерация** (когда подключат API) → прослушивание → отбор → загрузка в библиотеку с именованием по правилам (раздел 5).
7. **Передача в сведение**: таблица + утверждённые файлы → `mix_plan.md`.

Плотность для серии 2–3 мин (ориентир): 2–4 локации эмбиента, 15–40 SFX/фоли, 2–4 музыкальных трека, 1–3 стинга.

## 2. Шаблон таблицы звуков серии

Файл `studio/sound/epNN_sound_table.md`:

```markdown
# Звуки серии EP<NN>

| ID | Сцена/кадр | Таймкод (старт) | Синхро-точка | Тип | Описание (RU) | Промпт (EN) | Длит., с | Loop | prompt_influence | Громкость, LUFS | Панорама | Библиотека | Статус |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
```

Поля:
- **ID** — `epNN_<тип>_<NNN>`, например `ep01_hard_007`.
- **Сцена/кадр** — `sc03/sh05` по шот-листу.
- **Таймкод (старт)** — момент начала звука от начала серии, `ММ:СС.мс`.
- **Синхро-точка** — где именно должен прийтись пик звука (например, «удар на 00:41.20»); для эмбиента и музыки — «—».
- **Тип** — AMB / HARD / FOLEY / DES / MUS / STING / VOX.
- **Промпт (EN)** — по правилам раздела 3.
- **Длит., с** — для SFX: 0.5–30 с (ограничение API); для музыки — длина трека с запасом.
- **Loop** — `да` для эмбиента и фоновых петель, иначе `нет`.
- **prompt_influence** — 0–1 (по умолчанию в API 0.3). Для точных одиночных звуков 0.5–0.7, для эмбиента 0.3–0.4.
- **Громкость, LUFS** — целевой уровень клипа в премиксе (из `sound_bible.md`, п. 5.2).
- **Панорама** — C (центр), L30/R30 и т. п.; диалог всегда C.
- **Библиотека** — `new` или ID существующего файла.
- **Статус** — `план` → `сгенерировано` → `утверждено` / `перегенерировать`.

## 3. Правила промптов

Для SFX (`POST /v1/sound-generation`, модель `eleven_text_to_sound_v3` — у v2 объявлен вывод из эксплуатации 1 марта 2027):
- Формула: **источник + действие + материал/поверхность + пространство + характер/перспектива**. Пример: «Wooden door creaks open slowly in a quiet empty house, close perspective».
- Сложные звуки описывать последовательно: «footsteps on gravel, then a gate opens».
- Аудиотермины помогают: impact, whoosh, riser, drone, ambience, foley, tail.
- В конце промпта эмбиента — «no music, no speech», если голоса не нужны.
- Один звук — один промпт. Не смешивать в одном файле шаги, речь и музыку: смешивание делаем в сведении.
- Длительность задавать явно (`duration_seconds`), иначе модель выберет сама.
- Оригинальность: без названий фильмов, игр, тайтлов и «как в …».

Для музыки (`POST /v1/music`):
- Брать «ядро» слота из `sound_bible.md` (п. 3.2) + хвост: интенсивность, длительность, особенности монтажа («ends with a clean resolved chord», «starts softly»).
- `force_instrumental: true` для всего фона.
- `music_length_ms` = длина участка × 1.2–1.3 (запас под монтаж).
- Для сложной драматургии внутри трека (тихо → нарастание → кульминация) — `composition_plan` с секциями вместо простого промпта.

Для голосов без слов (VOX): вздохи, смешки, «а?!» персонажа — через TTS голосом персонажа; толпа, массовка — через SFX («small crowd gasps in surprise, indoor hall»).

## 4. Эмбиент локаций

### 4.1. Карточка локации

Хранится в `studio/sound/library/ambience/<location_id>.md`:

```markdown
# Эмбиент: <локация>
| Поле | Значение |
|---|---|
| location_id | loc_<имя> |
| Интерьер / экстерьер | |
| Варианты времени суток / погоды | день / ночь / дождь |
| Слой 1 — база (loop) | промпт EN, 20–30 с, loop=да |
| Слой 2 — детали (one-shots) | 3–6 коротких звуков: промпты EN, 1–5 с |
| Слой 3 — комнатный тон (для интерьеров) | промпт EN, loop=да |
| Уровень | база −32 LUFS; детали −28…−34 |
| Звуковая подпись | 1 узнаваемый элемент локации (часы, ветряной колокольчик, гул вентиляции) |
```

### 4.2. Правила
1. **Двухслойность.** База — ровная петля без ярких событий (её можно растянуть на любую длину). Детали (птица, далёкий гудок, скрип) — отдельными one-shot файлами, расставленными вручную с интервалом 4–12 с и случайной панорамой. Так петля не «узнаётся» на повторах.
2. **Петли.** База генерируется с `loop: true` на 20–30 с и растягивается до длины сцены в ffmpeg (`aloop` + `atrim`, см. `mix_plan.md`). Стыки проверяются на слух.
3. **Подпись локации.** У каждой локации один повторяющийся характерный элемент — по нему зритель узнаёт место. Он звучит в первые 2 секунды сцены.
4. **Непрерывность.** Внутри одной локации эмбиент не прерывается на сменах кадров, даже если меняется крупность плана. Меняется только громкость (на крупном плане лица — тише на 2–3 dB).
5. **Переходы между локациями.** Кроссфейд 0.3–0.5 с на стыке. Для плавности — **звук ведёт картинку (J-cut)**: эмбиент новой сцены начинается за 0.5–1 с до смены кадра. Для резкого контраста — жёсткая склейка без фейда (приём, используется намеренно).
6. **Никакой полной тишины.** В интерьерах минимум — комнатный тон −40…−45 LUFS. Полная тишина — только как режиссёрский приём (≤ 2 с), с пометкой в таблице.
7. **Время суток и погода** — отдельные варианты базы одной локации, а не новые локации (`loc_school_day`, `loc_school_night`).
8. **Без музыки и речи в эмбиенте.** Если в локации нужна разборчивая речь массовки — это отдельная дорожка VOX.
9. **Ducking эмбиента** под диалог — 2–4 dB (автоматически в сведении).

## 5. Именование и хранение файлов

- Формат: `<scope>_<type>_<slug>_v<N>.wav`, всё латиницей, нижний регистр.
  - `lib_amb_city-rain-night_v1.wav`, `ep01_hard_metal-door-slam_v2.wav`, `lib_mus_theme-full_v1.wav`.
  - `lib_` — переиспользуемые библиотечные, `epNN_` — одноразовые для серии.
- Исходник из API хранится как есть (`.mp3`), рабочая копия — `.wav` 48 кГц / 24 бит.
- Для каждого сгенерированного файла в манифест пишутся: промпт, модель, параметры (duration, loop, prompt_influence, seed если есть), дата.
- Где физически лежат аудиофайлы (git LFS, облачное хранилище, локальный каталог конвейера) — решение за IT-специалистом; в git под `studio/sound/` хранятся только тексты (таблицы, манифесты, карточки).

## 6. Приблизительный расход кредитов (оценка, сверить с тарифом)

- SFX: по документации при явно заданной длительности — около 40 кредитов за секунду. Серия: ~30 звуков × ~3 с × 2 дубля ≈ 7 000 кредитов; эмбиент — 2–4 петли × 30 с ≈ 2 400–4 800 кредитов (только для новых локаций).
- Музыка и TTS — тарификация зависит от плана; посчитаем после выбора тарифа. Ожидаемо, что основная статья расходов первых серий — библиотека музыки (разовые затраты), дальше — диалоги и новые SFX.
