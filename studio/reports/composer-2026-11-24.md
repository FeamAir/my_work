## Что сделано (бесплатно)

### 1. Сверка API (openapi.json ElevenLabs, 2026-11-24)
- `POST /v1/music`, модели `music_v1` (deprecated) / `music_v2` / `music_v2_5`. `composition_plan.chunks`: 1–30 чанков по 3 000–120 000 мс, `text` ≤ 6 132 симв., ≤ 30 строк по ≤ 200 симв. Также есть `seed` и `store_for_inpainting`, `song-id` возвращается в заголовке ответа. Для v2/v2.5 длительности секций соблюдаются всегда.
- **Ошибка в плане v0.2 найдена и исправлена:** `condition_strength` в схеме — поле внутри `conditioning_ref` (AudioRefChunk), а не поле чанка. В `opening_song.md` §5.2 он стоял на уровне чанка, и запрос бы отклонился или проигнорировал силу. В новом JSON исправлено.
- Появились `/v1/music/stem-separation` (стемы у самой ElevenLabs, платно) и `/v1/music/upload`. Инструментал и чистый вокал по-прежнему делаем бесплатным локальным сепаратором (§5.1, шаг 4).
- **Цена в кредитах официально не подтверждена:** elevenlabs.io (страницы цен и справки) закрыт сетью среды (proxy 403). Сторонние источники дают ≈ 900 кредитов/мин в приложении и $0,15–0,30/мин в API, а по `music_v2_5` отдельной цифры нет. Поэтому раннер **меряет реальную цену каждого дубля** по разнице `character_count` до и после вызова (бесплатный запрос) и пишет её в журнал. Для проверки лимита до вызова берётся пессимистичная ставка 2 500 кр/мин.
- **Смета в худшем случае:** тема 2 × 96 с + песня 4 × 90 с = 9,2 мин × 2 500 = **23 000 кр < 25 000**. При ≈ 900 кр/мин — ≈ 8 300 кр. После первого замера ставку можно уточнить (`--rate`).

### 2. Порядок генерации (изменён: без эскиза)
Мастера темы нет (`lib_mus_theme-master_v1` никогда не генерировался, проверено по `output/costs.jsonl`). Шаг «эскиз» (§5.1) директор фактически отменил («≤ 4 полных дубля»). Поэтому:
1. **Мастер темы** (задача 2): ≤ 2 дубля, план `theme_master_plan_v1.json` (= `main_theme.md` §7 без изменений), `store_for_inpainting: true`. Выбранный дубль даёт `THEME` song_id.
2. **Песня** (задача 1): ≤ 4 дубля, план `op_song_plan_v1.json`. Ссылки `SKETCH` заменены на `THEME`: грув → THEME 12–24 с, припев и финальный припев → крючок THEME 60–72 с, все `medium`. С a cappella-интро ссылка снята: инструментальная ссылка тянула бы оркестр в соло голоса. Дубли 1–2 — `medium` с разными seed. Если октавный скачок «Sing — LOU-» не держится, дубли 3–4 меняют подход (`high` на припевах), а не повторяют то же.
3. Отбор → нарезки (§4, §6) → стемы локально → R2. Всё бесплатно.

### 3. Инструменты (в `studio/music/gen/`)
- `run_music.py` — один дубль за вызов. Проверяет план по схеме API. Не отправляет неразрешённые `THEME/SKETCH`. Держит **жёсткий лимит** по журналу `output/music/gen_ledger.jsonl` (`--cap 25000`), меряет кредиты, пишет в `output/costs.jsonl` через `pipeline.costs` (кредиты и song_id в `extra`), заливает дубль в R2 `music/S01/takes/` через `pipeline.storage`, mp3 кладёт в `output/music/`. `--dry-run` прогнан на обоих планах: валидация пройдена, платного вызова нет.
- `check_take.py` — бесплатные объективные проверки: длина и ближайшая тактовая черта (такт 3,0 с), LUFS и true peak, уровень ниже 90 Гц относительно полной полосы (правило «без дрона и саба»), файл `_phone.wav` (ФВЧ 300 Гц + ФНЧ 8 кГц, моно) для телефонного теста. Проверен на синтетическом сигнале.

Команды после «ворота открыты»:
```
python3 studio/music/gen/run_music.py studio/music/gen/theme_master_plan_v1.json --name theme-master --take 1 --seed 8011
python3 studio/music/gen/run_music.py studio/music/gen/theme_master_plan_v1.json --name theme-master --take 2 --seed 8012   # только если дубль 1 брак
python3 studio/music/gen/run_music.py studio/music/gen/op_song_plan_v1.json --name op-song --take 1 --seed 4201 --theme-id <THEME>
... take 2 (seed 4202); takes 3–4 — только после разбора 1–2
```

### 4. Чек-лист отбора песни (из `opening_song.md` §1.1, §5.1, задача директора)
| # | Критерий | Как проверяю |
|---|---|---|
| 1 | Телефонная полоса: скачок C♯4 → C♯5 на «Sing — LOU-» и слова припева узнаются | `_phone.wav` на слух |
| 2 | Нет запретного тона A♯/B♭: нет мажорного F♯, нет модуляции, финал — пустая квинта | на слух + спектр финального аккорда |
| 3 | Крючок пропевается после одного прослушивания | на слух (композитор, затем директор) |
| 4 | Длина 1:30,0 или режется по тактовой черте (3,0 с) с чистым хвостом к 1:30 | `check_take.py` |
| 5 | Один голос, не оперный, без хора и «ooh» | на слух |
| 6 | Нет тонального гула ниже F♯2 | `check_take.py` (sub_vs_full) + спектр |
| 7 | Нет сходства с известными песнями | на слух |

## Задача 2: эндинг пилота
Готового материала нет: мастер темы не генерировался. Генерация входит в тот же лимит, см. п. 2. **Точка входа эндинга (вопрос из v4 §3.2):** предлагаю мастер с 0:00. Первые ≈ 24 с (соло виолончели, фраза A, затем тихий грув) — самое тихое место, подходит под страницу Хроники. Крючок звучит только на 1:00, через ≈ 20 минут после опенинга. Если на сборке повтор крючка мешает, вариант «без крючка»: 0:00–0:48 + 1:24–1:36 (60 с, склейка по тактовой черте). Решаю по слуху после мастера, бесплатно.
