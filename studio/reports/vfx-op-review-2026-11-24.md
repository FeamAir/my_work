**Вердикт: раскадровка хорошая, её можно собирать. Перед генерацией нужно пять правок.** Музыкальная сетка точная, бюджет реальный, правила канона учтены. При этом есть три слабых места:

**Топ-5 изменений** (подробно в §4; деньги не добавляются, а освобождаются $0.27):
1. Стекло делаем видимым событием: фронт «замерзания» идёт по гавани ступенями, по ударам.

## 2. Склейки: надёжность движения Kling и выполнимость VFX

### 2.1 Общие правки ко всем промптам Kling

1. **Убрать «Subtle» из префикса для экшен-клипов** (K01, K01a, K04, K11, K12, K14, K15). В видеотесте «Subtle 2D anime animation» отлично гасил движение, а здесь он будет гасить волну и знамёна. Префикс для экшена:
   `2D anime animation, the colors and line art stay exactly as in the source image, stable outlines, no morphing, consistent lighting, no new light sources, no glowing marks.`
   Для K03, K07, K08, K09, K17 префикс «Subtle…» оставить.
2. **Одно действие на клип.** Kling 2.5 TP надёжно делает одно непрерывное движение за 5 с. Формулы вида «сначала…, потом…» («hangs, and falls back», «from rest, slowly at first, then steadily», «at first choppy… then die down») он выполняет непредсказуемо, а тайминг фаз не контролируется. Смену фаз делаем монтажом: спид-рамп, склейка, шторка.
3. **Где поверх кладём свой SHAKE, писать `Locked-off camera, no camera shake`.** Иначе тряска удвоится и картинка «поплывёт».
4. **Слова «explodes», «crash» и «fast» убрать.** Kling читает их как взрыв, дым и обломки, а при быстрой камере стены «кипят». Это красный список из `water_and_disaster.md` §2.
5. **Направление вращения словами не задаётся:** модели путают clockwise и counter-clockwise и могут развернуть колесо посреди клипа. Где направление важно (OP-8, по солнцу), вращение делаем в ffmpeg.
6. Выход Kling 1928×1072 подгонять так: `scale=1940:1080,crop=1920:1080`. Апскейл 0.75%, нужно учесть в каждом проходе.

## 3. Рецепты ffmpeg (проверены на ffmpeg 6.1.1 и testsrc2 1920×1080/24, все отработали)

Общий порядок прохода (L-правило): плита, затем эффекты «в мире» (брызги у дамбы, каустика, тени облаков), затем движение камеры (PUSH/PX/SHAKE/WHIP), затем экранные эффекты (дождь на объективе, POP, INK), затем грейд и зерно. **Тряска всегда последней среди движений камеры** и всегда на плите с запасом не меньше 1.05×.

### 3.1 SHAKE: на каждую долю плюс большой удар
```bash
# 0.5 = первая доля в куске, 0.75 = период доли; 1.5 = большой удар в куске (локальное время)
-vf "scale=2016:1134,crop=1920:1080:\
x='48+gte(t,0.5)*8*exp(-9*mod(t-0.5,0.75))*sin(2*PI*14*t)+gte(t,1.5)*20*exp(-4*(t-1.5))*sin(2*PI*11*t)':\
y='27+gte(t,0.5)*6*exp(-9*mod(t-0.5,0.75))*sin(2*PI*17*t+1)+gte(t,1.5)*14*exp(-4*(t-1.5))*sin(2*PI*9*t+2)'"
```
- `exp(-9·…)`: удар на доле гаснет за ≈4 кадра;
- `exp(-4·…)`: большой удар гаснет за ≈1 с;
- амплитуды: 6–12 px на долю, 20 px на 0:57/1:09/1:22.5 (запас 48/27 px покрывает до 24 px);
- разные частоты по x и y, чтобы тряска не выглядела «восьмёркой».

Для 1.5-секундных склеек грува удобнее давать удар только на первую долю склейки: `gte(t,0)*…*exp(-9*t)`.

### 3.2 POP и INK
```bash
# POP: +0.06 на 2 кадра на каждой доле с 0.5 с
eq=brightness='0.06*gte(t,0.5)*lt(mod(t-0.5+0.0001,0.75),0.084)':eval=frame
# INK: 2 кадра негатив + постеризация в сине-чёрный/лён (на 1.5 с куска)
negate=enable='between(t,1.5,1.583)',lutyuv=y='if(lt(val,90),16,if(lt(val,170),120,225))':u=128:v='val*0.6+51':enable='between(t,1.5,1.583)'
```
Вспышки по канону: только экспозиционный POP или тёмный INK-кадр, никакого белого засвета и никакого источника в кадре (OP-3). «Свет» как событие делаем только мотивированным: луч из разрыва облаков (§3.7).

### 3.3 WHIP: рывок камеры с направленным смазом
```bash
# вертикальный рывок в последние 0.5 с склейки 3 с; смаз ступенями 12 → 40 по вертикали
-vf "scale=1920:1620,crop=1920:1080:0:'540-540*pow(max(0,(t-2.5)/0.5),2)',\
gblur=sigma=0.5:sigmaV=12:enable='between(t,2.75,2.875)',gblur=sigma=0.5:sigmaV=40:enable='gte(t,2.875)'"
```
- для горизонтального рывка `sigma` (горизонталь) поставить большим, `sigmaV` маленьким, а движение кропа вести по x;
- входная половина: 4 кадра с убывающим смазом на следующей склейке;
- склейка стоит точно на доле;
- больше 4 рывков в опенинге не делать (правило v1.1 верное).

### 3.4 RAMP: спид-рампы
```bash
# 1/3 «на тройках» (крючок 01) + 2× со смешиванием пар кадров, одна склейка
-filter_complex "[0]split[a][b];[a]trim=2:3,setpts=3*(PTS-STARTPTS),fps=24[s];\
[b]trim=3:5,setpts=PTS-STARTPTS,tmix=frames=2,framestep=2,setpts=N/24/TB[f];[s][f]concat=n=2:v=1"
# плавное замедление 0.6× (вода, облака, титр) со смешиванием кадров
-vf "setpts=PTS/0.6,framerate=fps=24"
# ускорение 2.5× для рывка по каналу (склейка 28): смаз из трёх кадров
-vf "tmix=frames=3,setpts=PTS/2.5,fps=24"
```
Правила:
- замедление ниже 0.5× делать только «на тройках» (каждый кадр держится ровно 3 кадра) или через `framerate`;
- `minterpolate` (mci) не использовать: на рисованной картинке он рвёт контуры;
- 0.35× не брать никогда: получается неровный ритм 3–3–2.

### 3.5 SPRAY: брызги, вылетающие из точки удара
```bash
# поле капель (один раз)
ffmpeg -f lavfi -i "color=black:s=1920x1080,format=gray,geq=lum='if(gt(random(1),0.9993),255,0)',gblur=sigma=2.2,lut=y='min(val*14\,255)'" -frames:v 1 -update 1 drops.png
# радиальный разлёт из точки (0.5W, 0.72H): zoompan по полю = капли уходят от центра, быстро и с торможением
-filter_complex "[1]zoompan=z='1+1.2*(1-exp(-on/20))':x='iw*0.5-(iw/zoom)*0.5':y='ih*0.72-(ih/zoom)*0.72':d=1:s=1920x1080:fps=24,\
gblur=sigma=1:sigmaV=3,format=gbrp[p];[0]format=gbrp[v];[v][p]blend=all_mode=screen:all_opacity=0.5,format=yuv420p"
```
- Гравитация: второй слой с крупными каплями (`sigma=4`, порог 0.99985) через `overlay=y='-300*t+260*t*t'`, то есть вверх и обратно вниз.
- Маска брызг из K01: `lutyuv=y='if(gt(val,200),255,0)',gblur=sigma=6`, затем `alphamerge`. Так белые брызги клипа становятся маской для дополнительной дымки.
- Цвет брызг: серо-белый, `all_opacity` 0.35–0.6. На светлой плите эффект почти не виден, поэтому плиту под брызгами затемнить на 10%.

### 3.6 RAIN
Базовый рецепт L-06 рабочий. Что поправить для дневного шторма:
1. Перед дождём затемнить плиту: `eq=brightness=-0.05:contrast=1.08`. Без этого дождь на дневной плите не читается (это же сказано в примечании к L-06).
2. Два слоя:
   - дальний: `scroll=vertical=-0.03`, opacity 0.3;
   - ближний: поле с `sizeY=40`, `scroll=vertical=-0.07`, opacity 0.6.
3. **Один угол на все штормовые склейки 25–30** (`rotate=a=0.22`, ветер слева, как у знамён). Если угол дождя меняется от склейки к склейке, ломается география.

### 3.7 Тени облаков и прокатывающийся свет (бесплатная «жизнь» для LA-плит)
```bash
# поле облаков (один раз): шум → сильное размытие → нормализация → растяжение 3× по ширине
ffmpeg -f lavfi -i "color=black:s=1440x270,format=gray,geq=lum='random(1)*255',gblur=sigma=18,normalize=blackpt=black:whitept=white,scale=5760:1080" -frames:v 1 -update 1 clouds.png
# тени бегут по плите (multiply, глубина 28%)
-filter_complex "[1]crop=1920:1080:'t*260':0,lutyuv=y='255-0.28*(255-val)',format=gbrp[c];[0]format=gbrp[v];[v][c]blend=all_mode=multiply,format=yuv420p"
```
- **Прокатывающийся свет** («прошёл день»): мягкая диагональная полоса `geq` (один раз, PNG), которая едет через кадр за 3 с; наложение `blend=softlight` с прозрачностью 0.25. Для OP-9 полоса идёт с запада, то есть от моря.
- **Луч из разрыва облаков** (склейка 30): та же полоса, вертикальная, раскрывается через `crop` по ширине. Источник (разрыв) должен быть в кадре.

### 3.8 Ступица колеса (склейка 05, вместо K06)
```bash
# покой до 0.5 с куска (= 0:12.0), разгон с ускорением, потом ровно 1.8 рад/с; положительный угол = по часовой (OP-8)
-filter_complex "[0]split[bg][w];[w]rotate=a='gte(t,0.5)*(lt(t,1.5)*0.9*pow(t-0.5,2)+gte(t,1.5)*(0.9+1.8*(t-1.5)))':c=none,\
format=rgba,geq=r='r(X,Y)':g='g(X,Y)':b='b(X,Y)':a='255*lt(hypot(X-CX,Y-CY),R)'[r];[bg][r]overlay[o];[o][post]overlay"
```
- `CX`, `CY`, `R`: центр и радиус обода на sc06-sh010;
- `[post]`: стойка и распорка, вырезанные из плиты прямоугольной маской, кладутся поверх вращения;
- повёрнутые копии стойки внутри круга выглядят как толстые спицы, в смазе это нормально.

Чтобы штамп на 0:12.0 «толкнул» колесо, поверх идёт SHAKE и POP на ту же долю.

### 3.9 Монета-волчок (склейка 14)
```bash
-filter_complex "[1]scale=w='max(4,200*abs(cos(2*PI*t*(3.5-1.0*t))))':h=200:eval=frame[c];[0][c]overlay=x='X0-w/2':y=Y0:eval=frame"
```
- частота вращения падает со временем, и монета «засыпает»;
- спрайт монеты вырезать из F14;
- на узких фазах (`w<40`) подменить спрайт на тёмный ребристый край, это классический рисованный волчок;
- последний оборот закончить на доле 0:35.25.

### 3.10 Ложный рывок вперёд (запасной вариант для 28): зум-смаз
```bash
-filter_complex "[0]zoompan=z='1+0.35*on/36':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=36:s=1920x1080:fps=24,split=3[a][b][c];\
[b]scale=iw*1.03:-2,crop=1920:1080[b2];[c]scale=iw*1.06:-2,crop=1920:1080[c2];\
[a][b2]blend=all_mode=average[ab];[ab][c2]blend=all_mode=average"
```
Три копии с шагом масштаба 3% дают радиальный смаз от точки схода. Сверху кладётся косой быстрый дождь.

### 3.11 Стекло: фронт «замерзания» (правка 1)
```bash
# A = K13 (штормовая рябь), B = плита D09_H2 (стекло); 4 ступени, каждая быстро «прыгает» в первую треть интервала и держится
# ВНИМАНИЕ: в xfade custom P идёт от 1 к 0 — поэтому (1-P). Фронт уходит ОТ камеры к горизонту (Шпили за спиной камеры, на востоке, OP-9)
[A][B]xfade=transition=custom:duration=6:offset=OFF:expr='st(0,(1-P)*4);st(1,ld(0)-floor(ld(0)));st(2,(floor(ld(0))+min(1,ld(1)*3))/4);\
if(gt(Y/H+0.04*sin(X/W*31)+0.02*sin(X/W*97),1.05-ld(2)*1.1),B,A)'
```
- Волнистая кромка: две синусоиды. Вариант: добавить статичную карту шума `geq` из PNG через `blend`.
- Кромку смягчить вторым проходом с `gblur=sigma=6` по маске, если в проверке она будет выглядеть «ножницами».
- Свечения на фронте нет (OP-3). Только граница: за ней стоит зеркало, перед ней рябь.

### 3.12 Титр
```bash
# логотип: влетает с перебором 114% → 100% и затухающим «пружинящим» колебанием за ≈8 кадров, альфа за 4 кадра
-filter_complex "[1]scale=w='LW*(1+0.14*exp(-t*9)*cos(t*22))':h=-1:eval=frame,fade=t=in:st=0:d=0.17:alpha=1[l];\
[0][l]overlay=x='(W-w)/2':y='H*0.30-h/2':eval=frame"
# стирка брызгами (склейка 32 → 33): рваная шторка снизу вверх + брызги K01 (screen) поверх кромки
[g][t]xfade=transition=custom:duration=0.5:offset=OFF:expr='if(gt(Y/H+0.06*sin(X/W*23)+0.03*sin(X/W*71),P*1.12),B,A)'
```
- Принцип: **кромку шторки прячет элемент.** Сверху на 0.5 с кладётся увеличенный на 1.6× столб брызг K01 (`blend=screen`, 0.6).
- Маска только из яркости K01, как в v1.1, не годится: брызги K01 локальны и весь кадр не закроют.
- Ось шторки вертикальная, отражения кадра нет (OP-11).
- Порядок на 1:22.5: INK 2 кадра → шторка → логотип садится → 6 кадров SHAKE → неподвижно.
