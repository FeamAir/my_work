# Методика консистентности персонажей и локаций

Версия 1.0 · 2026-11-22 · автор: режиссёр-постановщик

Главная проблема AI-аниме: модель «перерисовывает» персонажа в каждом кадре заново. У нас четыре уровня защиты:

1. **Канон**: утверждённые референс-листы.
2. **Текст**: фиксированный ID-блок дескрипторов, который копируется слово в слово.
3. **Генерация по референсу**: ключевой кадр делается в edit/reference-режиме с картинками канона, а не по одному тексту.
4. **Приёмка**: чек-лист из раздела 6, без которого кадр не идёт в оживление.

---

## 1. Референс-листы персонажа (делаются один раз на персонажа)

Папка: `studio/direction/refs/<character_id>/` (создаётся, когда появятся персонажи от сценариста).

| Файл | Содержание | Как получить |
|---|---|---|
| `00_master.png` | «Паспортное фото»: поясной портрет 3/4, нейтральная эмоция, ровный свет, нейтральный кремовый фон | text-to-image, 8–16 вариантов, режиссёр выбирает один |
| `01_turnaround.png` | Полный рост: фронт / 3/4 / профиль / спина в одну строку, T-поза или спокойная стойка, один фон | edit-режим от `00_master` |
| `02_front.png`, `03_three_quarter.png`, `04_profile.png` | Отдельные крупные головы в трёх ракурсах | edit-режим от `00_master` |
| `05_emotions.png` | Сетка 2×3 эмоций: нейтральная, радость, грусть, гнев, удивление, страх | edit-режим от `02_front` |
| `06_mouth.png` | Рты для липсинка: закрыт, «А», «О», «И», «М/Б/П», улыбка | edit-режим, нужен звукорежиссёру/липсинку |
| `07_palette.png` | Цветовые плашки персонажа с HEX: кожа, тень кожи, волосы, тень волос, глаза, одежда 1–3 | вручную по `00_master` (пипетка) |
| `08_props.png` | Ключевые аксессуары/оружие крупно | edit-режим |
| `card.md` | ID-блок, HEX, запреты, рост относительно других | пишет режиссёр |

Правила:
- Референс генерируется **в стиле визуальной библии** (базовый стилевой промпт), на нейтральном фоне, при нейтральном тёплом свете — иначе освещение «запечётся» во внешность.
- После утверждения референс-лист **заморожен**. Изменения костюма — новый файл с суффиксом (`01_turnaround_winter.png`) и новая версия ID-блока.
- Хранить исходный промпт, модель, seed и дату генерации рядом с каждым референсом (`card.md`).

## 2. ID-блок персонажа (фиксированные дескрипторы)

Короткое (40–70 слов) английское описание, которое вставляется **дословно и в одном и том же порядке** во все промпты с персонажем. Нельзя перефразировать, сокращать или менять порядок.

Шаблон:
```
[ID: <NAME>] <age-group> <gender>, <body build>, <height cue>;
hair: <color> <length> <style>, <unique hair feature>;
eyes: <color>, <shape>;
face: <distinctive feature>;
outfit: <main garment + color>, <secondary + color>, <shoes>;
signature item: <one unique accessory, where it is worn>
```

Пример (тестовый персонаж, не из сценария):
```
[ID: MIRA] young woman around 20, slim build, average height;
hair: ash-blonde shoulder-length bob, small green leaf-shaped hair clip on the right side;
eyes: amber, slightly droopy outer corners;
face: small mole under the right eye;
outfit: oversized mustard-yellow knit sweater, dark navy pleated skirt, brown ankle boots;
signature item: round brass pocket watch on a chain around the neck
```

Принципы:
- Каждый персонаж должен иметь **минимум 2 «якоря»**: уникальную деталь причёски и уникальный аксессуар. Модели держат якоря лучше, чем общие черты лица.
- Цвета называть простыми словами + один уточнитель (`mustard-yellow`, а не `#D9A63B` — HEX модели понимают плохо).
- Сторону асимметричных деталей указывать всегда (`on the left side`) и проверять при приёмке.
- Не давать двум персонажам одинаковые цвета волос или основной одежды.
- Имя в `[ID: …]` — служебное; модели часто его игнорируют, но оно помогает при автоматической сборке промптов.

## 3. Генерация ключевого кадра по референсу

Порядок предпочтения режимов (конкретную доступность эндпоинтов на fal.ai подтверждает IT-инженер):

1. **Edit / multi-reference-режим** (Nano Banana / Nano Banana 2 edit, Seedream edit, FLUX Kontext): на вход подаются картинки-референсы + текст. Это основной режим студии.
   - Вход: `02_front` или `03_three_quarter` (по ракурсу кадра) + `01_turnaround` + мастер-локация.
   - Текст: «Use the character from image 1 exactly (same face, hair, outfit, colors). Place her in the location from image 3. …» + ID-блок + действие + стиль.
   - Два персонажа: по одному референсу на каждого, в тексте явно «the girl from image 1 stands on the left, the man from image 2 on the right».
   - Не более 3–4 референсов за раз: дальше качество смешения падает.
2. **Инпейнт/правка готового кадра**: если внешность почти верна, исправлять точечно edit-запросом («change only the sweater color to mustard-yellow, keep everything else»), а не перегенерировать целиком.
3. **Text-to-image** — только для пейзажей и кадров без персонажей.

Приёмы:
- **Мастер-локации**: каждая локация генерируется один раз без персонажей (общий план + 2–3 ракурса) и далее подаётся как референс. Это держит интерьер стабильным.
- **Мастер-кадр сцены**: для диалоговой сцены сначала делается один общий кадр с обоими персонажами; средние и крупные планы делаются edit-ом от него («close-up of the girl from this image, same lighting»). Так совпадают свет и одежда.
- **Seed**: фиксировать seed для дублей одного кадра (там, где модель его принимает), менять только при неудаче.
- Ракурс кадра должен совпадать с ракурсом поданного референса: для профиля подавать `04_profile`.

## 4. Оживление (image-to-video)

- Видео всегда делается **только из утверждённого ключевого кадра** (image-to-video), никогда text-to-video для кадров с персонажами.
- Промпт движения описывает **только движение**, внешность не пересказывается (иначе модель начинает её «улучшать»). Добавляется базовый промпт движения из визуальной библии.
- Одно действие на клип. Сложное действие делится на 2 клипа: второй начинается с **последнего кадра первого** (extract last frame → новый ключевой кадр, проверка по чек-листу → оживление).
- Если модель поддерживает конечный кадр (start + end frame), для переходов поз использовать его: оба кадра делаются заранее и проверяются.
- Клипы генерируются длиной, кратной минимальной у модели (обычно 5 с), и подрезаются на монтаже — берём самый стабильный отрезок (как правило, первые 2–4 с: дрейф внешности растёт к концу клипа).
- Реплики крупным планом: сначала оживление без речи (лёгкое моргание, дыхание), затем отдельный липсинк поверх (см. model_choice.md).

## 5. Версионирование

Имя файла кадра: `ep01_sc03_sh012_kf_v2.png` / `ep01_sc03_sh012_vid_v2_t1.mp4` (эпизод, сцена, кадр, тип, версия ключевого кадра, дубль видео). Утверждённая версия помечается в шот-листе в колонке «Статус».

## 6. Чек-лист приёмки кадра

Кадр проходит, только если все пункты «обязательно» = да. Режиссёр сравнивает кадр рядом с `00_master` и `07_palette`.

### Ключевой кадр (картинка)

**Обязательно:**
- [ ] Причёска: длина, форма, цвет и якорная деталь совпадают (сторона — правильная).
- [ ] Цвет глаз и форма совпадают; глаза симметричны, взгляд в нужную сторону.
- [ ] Одежда: все предметы на месте, цвета совпадают с палитрой персонажа (визуально, при сомнении — пипетка ±10% по тону).
- [ ] Якорный аксессуар присутствует и на своём месте.
- [ ] Отличительные черты лица (родинка, шрам) на месте и на правильной стороне.
- [ ] Пропорции и рост относительно других персонажей в кадре верны.
- [ ] Руки: правильное число пальцев, кисти не слиплись (если руки в кадре).
- [ ] Стиль: коричневый контур, одна ступень тени, живописный фон — не 3D, не фотореализм.
- [ ] Нет текста, водяных знаков, рамок, лишних людей.
- [ ] Композиция и план соответствуют шот-листу; соблюдено правило 180° (кто слева/справа).
- [ ] Формат 16:9, разрешение не ниже целевого (или пригодно для апскейла до 1080p).

**Желательно:**
- [ ] Свет совпадает с соседними кадрами сцены (направление ключа, время суток).
- [ ] Акцентный цвет сцены присутствует и не превышает ~10% площади.
- [ ] Есть «воздух» для движения: края кадра не обрезают голову/руки, которые будут двигаться.

### Видеоклип

**Обязательно:**
- [ ] Лицо не «плывёт» и не меняется на протяжении используемого отрезка.
- [ ] Причёска, одежда и аксессуар не меняются и не исчезают.
- [ ] Линия не мерцает заметно, фон не деформируется.
- [ ] Движение соответствует промпту движения и шот-листу, нет лишних действий.
- [ ] Нет появляющихся/исчезающих объектов и людей.
- [ ] Используемый отрезок ≥ длительности кадра по шот-листу.

**Желательно:**
- [ ] Движение мягкое, без рывков; скорость соответствует темпу сцены.
- [ ] Первый кадр клипа совпадает с ключевым кадром (нет «скачка» на старте).

Решение по итогам: **принят** / **дубль** (перегенерация видео тем же ключевым кадром) / **переделка ключевого кадра** / **упрощение кадра** (если 3 дубля не прошли — упрощаем действие или план, а не жжём бюджет).
