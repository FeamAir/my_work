# HERALDRY — master emblems (stage 2.5, 2026-11-23)

Drawn by hand as SVG (free, plan §2.5 decision: SVG path). Generator script logic: flat fills, dark umber outlines, subtle cloth texture. Each emblem: `.svg` (master, editable, scalable) + `.png` 512×512 render.
Spirals are computed (Archimedean / logarithmic, angle increasing in screen coordinates) — **clockwise from the centre outward by construction**. `H16_ashare_reference_spiral` is the series reference spiral; pass it as a reference image to any generation that must show a spiral.
