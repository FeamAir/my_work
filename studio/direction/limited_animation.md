# Библиотека приёмов ограниченной анимации (LA)

Версия 1.0 · 2026-11-22 · автор: режиссёр-постановщик
Связано: `visual_bible.md` §8–9, `model_choice.md`, `animatic.md`, `pipeline/assemble.py` (склейка и звук).

**Что это.** Классический приём ТВ-аниме: кадр — статичный рисунок (или 2–3 рисунка), а жизнь ему дают камера, слои, свет, частицы и звук. У нас всё это собирается в ffmpeg **бесплатно**: платим только за ключевой кадр ($0.04–0.08), а не за секунды видео ($0.015–0.14 за секунду).

**Проверено.** Все рецепты ниже прогнаны на ffmpeg 6.1.1 в нашей среде на синтетических плитах 1920×1080 (2026-11-22): команды работают, время рендера указано для 4-секундного кадра на CPU. Художественное качество проверяется на стилевом тесте на реальных кадрах — тогда уточню параметры (скорости, прозрачности).

Production notes пилота: **60–65% хронометража — LA**. По сценам: `story/episodes/S01E01/production_notes.md` §2.

---

## 1. Когда LA допустима, а когда нужен настоящий клип

### LA без ущерба качеству

| Ситуация | Почему работает |
|---|---|
| Пейзажи, establishing, город, Шпили без песни, интерьеры без людей | движение камеры по живописи — норма жанра |
| Документы, карты, гобелен, ведомости, надписи | камера + появление слоёв; анимация «внутри» не нужна (гобелен — запрещена) |
| Тишина, ожидание, слушание, оцепенение (перья в Sc 16, зал после падения) | неподвижность и есть смысл; живут свет, пыль, звук |
| Средний план слушающего, реакция без жеста | дыхание/моргание дают 2–3 рисунка (L-12) |
| Толпа: спины, силуэты, шлемы, цветовые блоки | движение толпы — частицами, светом, параллаксом, звуком |
| Погода и стихия как фон: дождь, туман, дым, рябь, каустика, поднимающаяся вода | эффекты поверх плиты (L-06…L-11, L-15) |
| Вставки предметов (камень на шнурке, зажим, чашка, перстень) | наезд + блик + звук |
| Говорящий спиной/в профиль далеко, закадр | рот не виден — синхрон не нужен |

### Нужен настоящий клип (image-to-video)

| Ситуация | Почему |
|---|---|
| Действие тела с причиной и следствием: шаг, падение, бросок, удар, захват, подъём из воды | LA не умеет менять позу правдоподобно |
| **Руки в действии**: засов, рука на рту, клятва-рукопожатие, удар камертона, жесты Хора | руки — главный маркер «дёшево»; движение рук — только генерация (статичная рука — можно LA) |
| Вода как действие, а не фон: колыбель плывёт и поворачивается, кольца расходятся от предмета, гавань «стекленеет» в одном кадре | M1, M2, M3 — денежные кадры |
| Синхронная речь крупно | липсинк, бюджет 5 на пилот |
| Облёт/пролёт с изменением перспективы (Шпиль, гавань, армия) | параллакс не даёт поворота объёма |
| Ткань и волосы как **смысл** кадра (Иона в горле Шпиля, роба на ветру) | см. L-13 — короткая дешёвая генерация |

**Пограничные случаи** решаются так: сначала LA-версия в аниматике; если на просмотре кадр «мёртвый» — короткая дешёвая генерация (MiniMax, 6 с, ≈ $0.09); на дорогую модель — только если и она не держит.

**Правило честности:** если кадр требует действия, мы не маскируем его LA с плохим результатом. Либо генерируем, либо меняем постановку (действие за кадром, начало + результат, реакция другого — `emotion_direction.md`).

## 2. Подготовка плит

- **Размер исходника:** для движения камеры исходник должен быть **на 25–50% больше кадра** (2400–2880 px по ширине для 1080p), для панорам — широкая плита (21:9…32:9), для подъёма — высокая (9:21…9:32). Если модель отдаёт меньше — бесплатный локальный апскейл (Real-ESRGAN, аниме-вариант модели; CPU, медленно, но бесплатно) **до** LA. Разрешения Nano Banana / NB2 по режимам подтверждает IT-инженер.
- **Слои для параллакса:** фон, средний план, передний план — отдельными генерациями (передний план на однотонном фоне → ключ/маска) или вырезкой маски из готового кадра (edit-запрос «same image, only the foreground pilings on a flat green background», $0.04). Передний план — PNG с альфой.
- **Эффект-слои** (дождь, пыль, туман, кольца) генерируются ffmpeg-ом один раз и хранятся в библиотеке: `output/library/la/<код>_<имя>_v1.png|mp4`. Переиспользуются всеми сериями.
- **Формат работы:** 1920×1080, 24 fps, yuv420p, H.264 CRF 18 (финал); аниматик — 1280×720, CRF 23 (рендер в 2–3 раза быстрее).

Переменные в рецептах: `IN` — плита, `OUT` — результат, `D` — длительность, с.

## 3. Рецепты

### L-01 Медленный наезд / отъезд (плавный)

```bash
ffmpeg -y -loop 1 -framerate 24 -t $D -i IN.png -vf \
 "scale=w='trunc(1920*(1+0.12*t/$D)/2)*2':h=-2:eval=frame:flags=bicubic,crop=1920:1080,setsar=1,format=yuv420p" \
 -c:v libx264 -crf 18 OUT.mp4
```
- `0.12` — сила наезда за кадр (12%). Тихий наезд «камера слушает» — 0.03–0.06; драматический — 0.12–0.15. Отъезд: `(1+0.12*(1-t/$D))`.
- Центр наезда смещается через `crop=1920:1080:x=...:y=...`.
- Вариант через `zoompan` быстрее (2 с против 3 с на 4-с кадр), но на медленных наездах даёт ступенчатое «дрожание» — использовать только в аниматике.
- ⏱ ≈ 3 с рендера на 4 с кадра.

### L-02 Панорама по широкой плите

```bash
ffmpeg -y -loop 1 -framerate 24 -t $D -i WIDE.png -vf \
 "scale=-2:1080,crop=1920:1080:x='(iw-ow)*t/$D':y=0,format=yuv420p" -c:v libx264 -crf 18 OUT.mp4
```
- Плавный старт/стоп (ease): `x='(iw-ow)*(0.5-0.5*cos(PI*t/$D))'`.
- Скорость: не больше ~1/3 ширины кадра за секунду, иначе стробит на 24 fps.

### L-03 Подъём / вертикальная панорама (Sc 2 — город, 6 с)

```bash
ffmpeg -y -loop 1 -framerate 24 -t 6 -i TALL.png -vf \
 "scale=1920:-2,crop=1920:1080:x=0:y='(ih-oh)*(1-(0.5-0.5*cos(PI*t/6)))',format=yuv420p" -c:v libx264 -crf 18 OUT.mp4
```
Снизу вверх с плавным разгоном. Та же плита даёт вертикальную нарезку (L-18).

### L-04 Параллакс слоёв

```bash
ffmpeg -y -loop 1 -framerate 24 -t $D -i BG.png -loop 1 -framerate 24 -t $D -i FG.png -filter_complex \
 "[0]scale=2400:-2,crop=1920:1080:x='(iw-ow)*t/$D*0.3':y=(ih-oh)/2[b];\
  [1]scale=2600:-2[f];[b][f]overlay=x='-(w-W)*t/$D':y=H-h+200:shortest=1,format=yuv420p" \
 -c:v libx264 -crf 18 OUT.mp4
```
- Дальний слой движется в 3–5 раз медленнее переднего. Третий слой — ещё один `overlay`.
- Передний план (сваи, мостки, верёвки, дождевые струи) — тёмный и размытый (`gblur=sigma=3`), он «продаёт» глубину.
- ⏱ ≈ 3,5 с.

### L-05 Ручная камера (тряска)

```bash
ffmpeg -y -loop 1 -framerate 24 -t $D -i IN.png -vf \
 "scale=2016:-2,crop=1920:1080:x='(iw-ow)/2+6*sin(2*PI*t*1.3)+3*sin(2*PI*t*3.7)':y='(ih-oh)/2+4*sin(2*PI*t*1.1+1)',format=yuv420p" \
 -c:v libx264 -crf 18 OUT.mp4
```
Амплитуда 4–8 px — тревога; 15–25 px — удар, обвал. Только экшен и паника.

### L-06 Дождь

Слой (один раз):
```bash
ffmpeg -y -f lavfi -i "color=black:s=1920x1080,format=gray,geq=lum='if(gt(random(1),0.9975),255,0)',avgblur=sizeX=1:sizeY=22,lut=y='min(val*8\,255)'" \
 -frames:v 1 -update 1 rain_field.png
```
Наложение:
```bash
ffmpeg -y -i PLATE.mp4 -loop 1 -framerate 24 -t $D -i rain_field.png -filter_complex \
 "[1]format=gbrp,scroll=vertical=-0.045,rotate=a=0.12:fillcolor=black,format=gbrp[r];\
  [0]format=gbrp[p];[p][r]blend=all_mode=screen:all_opacity=0.55,format=yuv420p" -c:v libx264 -crf 18 OUT.mp4
```
- Плотность — порог `0.9975` (меньше — гуще); длина струй — `sizeY`; скорость — `scroll`; косой дождь — `rotate`.
- Для глубины — два слоя: дальний (мелкий, медленный, прозрачность 0.3) и ближний (крупный, быстрый, 0.6).
- На ярких дневных плитах дождь почти не виден — это правильно; дождь у нас — ночь и сумерки.
- ⏱ ≈ 6 с.

### L-07 Пыль в луче / пылинки / искры

```bash
ffmpeg -y -f lavfi -i "color=black:s=1920x1080,format=gray,geq=lum='if(gt(random(1),0.99985),255,0)',gblur=sigma=3,lut=y='min(val*25\,255)'" \
 -frames:v 1 -update 1 dust_field.png
ffmpeg -y -i PLATE.mp4 -loop 1 -framerate 24 -t $D -i dust_field.png -filter_complex \
 "[1]format=gbrp,scroll=vertical=0.004:horizontal=0.002[d];[0]format=gbrp[p];[p][d]blend=all_mode=screen:all_opacity=0.7,format=yuv420p" \
 -c:v libx264 -crf 18 OUT.mp4
```
- Пыль только в луче: умножить слой на маску луча (белая трапеция на чёрном, `blend=all_mode=multiply`) перед наложением.
- Искры/угли (с S3, бои): тот же слой, тёплый цвет (`colorchannelmixer`), `scroll=vertical=-0.02` (вверх).
- ⏱ ≈ 2,5 с.

### L-08 Туман / дымка / дым

```bash
ffmpeg -y -f lavfi -i "color=gray:s=96x54,format=gray,noise=alls=100:allf=u,scale=3840:1080:flags=bicubic,gblur=sigma=40,eq=contrast=2.2:brightness=-0.1" \
 -frames:v 1 -update 1 fog_field.png
ffmpeg -y -i PLATE.mp4 -loop 1 -framerate 24 -t $D -i fog_field.png -filter_complex \
 "[1]crop=1920:1080:x='(iw-ow)*t/40':y=0,format=gbrp[f];[0]format=gbrp[p];[p][f]blend=all_mode=screen:all_opacity=0.35,format=yuv420p" \
 -c:v libx264 -crf 18 OUT.mp4
```
- Туман над каналами — только в нижней трети (маска-градиент).
- Дым от трубы/фонаря: тот же слой, высокий и узкий, `scroll` вверх, маска-конус.
- ⏱ ≈ 4,5 с.

### L-09 Мерцание фонаря / огня

```bash
ffmpeg -y -i PLATE.mp4 -vf "eq=brightness='0.025*sin(2*PI*t*1.7)+0.015*sin(2*PI*t*5.3)':eval=frame,format=yuv420p" \
 -c:v libx264 -crf 18 OUT.mp4
```
- Это мерцание всего кадра (огонь — единственный свет). Если фонарь один из нескольких источников — наложить мягкое янтарное пятно (радиальный градиент PNG) с мерцающей прозрачностью поверх области фонаря.
- Гаснущие один за другим фонари (Sc 1, изображение 2): N пятен, у каждого `enable='lt(t,T_i)'` с плавным `fade` — от дальнего к ближнему.
- ⏱ ≈ 1,5 с.

### L-10 Рябь и «живая» вода (смещение)

```bash
ffmpeg -y -i PLATE.mp4 \
 -f lavfi -i "color=gray:s=1920x1080:r=24:d=$D,format=gray,geq=lum='128+6*sin(Y/7+T*4)'" \
 -f lavfi -i "color=gray:s=1920x1080:r=24:d=$D,format=gray,geq=lum='128+3*sin(X/40+T*2)'" \
 -filter_complex "[0]format=yuv444p[a];[1]format=yuv444p[x];[2]format=yuv444p[y];[a][x][y]displace=edge=smear,format=yuv420p" \
 -c:v libx264 -crf 18 OUT.mp4
```
- Применять **только к области воды** (маска): результат накладывается на исходную плиту через `alphamerge`/`overlay`.
- Амплитуда 3–6 px — рябь; 1–2 px — горячий воздух/жар (с S3).
- **Неспетая вода всегда движется** (`visual_bible.md` §3.1) — этот приём идёт почти на каждую плиту с водой.
- ⏱ ≈ 15 с (`geq` медленный). Ускорение: считать карту смещения один раз в 960×540, зациклить (`-stream_loop`) и масштабировать.

### L-11 Кольца на воде (библиотечный ассет M2 / M5)

Карта колец (один раз, 960×540 — быстрее; масштабируется):
```bash
ffmpeg -y -f lavfi -i "color=black:s=960x540:r=24:d=4,format=gray,geq=lum='clip(128+127*sin(hypot(X-480\,(Y-300)*2.2)/6-T*9)*exp(-abs(hypot(X-480\,(Y-300)*2.2)-T*90)/40)*exp(-T*0.4)\,0\,255)'" \
 -c:v libx264 -crf 18 -pix_fmt yuv420p rings_map.mp4
```
Как смещение воды:
```bash
ffmpeg -y -i PLATE.mp4 -i rings_map.mp4 -filter_complex \
 "[1]scale=1920:1080,format=gray,lut=y='128+(val-128)*0.15',format=yuv444p,split[x][y];[0]format=yuv444p[a];[a][x][y]displace=edge=smear,format=yuv420p" \
 -c:v libx264 -crf 18 OUT.mp4
```
- Центр колец `(480, 300)` и сжатие перспективы `*2.2` подгоняются под кадр. Для бликов колец — тот же слой через `blend=all_mode=softlight`.
- По production notes кольца строятся **один раз** и возвращаются: пруд (Sc 3), миска (Sc 20), дальше по сезонам. Для героического кадра пруда (M2) — сравнить на стилевом тесте с генерацией; если LA-кольца проходят, экономим дорогой клип.
- ⏱ ≈ 12 с карта + 3 с наложение.

### L-12 Два-три рисунка (моргание, вдох, рот, мелкий жест)

Классика ограниченной анимации: 2–3 ключевых кадра одного плана, сделанные edit-ом от основного ($0.04–0.08 за рисунок), сменяются по таймингу.
```bash
# A — глаза открыты (основной), B — закрыты: моргание 3 кадра (0,125 с) на 3-й секунде
ffmpeg -y -loop 1 -framerate 24 -t $D -i A.png -loop 1 -framerate 24 -t $D -i B.png -filter_complex \
 "[0]scale=1920:1080[a];[1]scale=1920:1080[b];[a][b]overlay=enable='between(t\,3.0\,3.125)',format=yuv420p" \
 -c:v libx264 -crf 18 OUT.mp4
```
- Моргание: раз в 3–5 с, 3 кадра. Вдох: рисунок с чуть поднятыми плечами, смена через наплыв 0,5 с.
- «Рот-хлопушка» для речи на среднем плане: 2–3 рисунка (закрыт / полуоткрыт / открыт), смена по громкости реплики. Скрипт переключения по огибающей аудио — задача IT-инженера (ffmpeg `astats` → таймкоды). Только для MS и дальше; крупно — липсинк.
- Edit-запрос: `same image, identical in every detail, only the eyes are closed` — проверять, что ничего больше не изменилось (сравнение A/B наплывом).
- ⏱ ≈ 2,5 с.

### L-13 Волосы и ткань: короткая дешёвая генерация + петля

Когда ветер в волосах/робе — смысл кадра, а тело неподвижно (Иона спиной в горле Шпиля; Кантор на лестнице; знамёна).
1. Клип 6 с на MiniMax H3 Max Turbo (≈ $0.09) из утверждённого ключевого кадра; промпт: `only the hair and robe move gently in the wind, the body and face stay still, camera static`.
2. Берём самый стабильный отрезок 1,5–2,5 с и делаем петлю туда-обратно:
```bash
ffmpeg -y -i CLIP.mp4 -filter_complex \
 "[0]trim=0:2,setpts=PTS-STARTPTS,split[a][b];[b]reverse[r];[a][r]concat=n=2:v=1,loop=loop=2:size=96,format=yuv420p" \
 -c:v libx264 -crf 18 OUT.mp4
```
(`size` = число кадров петли: 2 с × 24 × 2.) Получаем 12 с «живого» кадра за $0.09.
3. Поверх петли — L-01 (наезд) и эффекты: камера движется, ткань живёт.
- Не работает для шага, жеста, поворота головы — петля «туда-обратно» на таком движении видна сразу.

### L-14 Перевод фокуса

```bash
ffmpeg -y -i PLATE.mp4 -filter_complex \
 "[0]split[a][b];[b]gblur=sigma=12[bl];[a][bl]blend=all_expr='A*(1-min(T/2\,1))+B*min(T/2\,1)',format=yuv420p" \
 -c:v libx264 -crf 18 OUT.mp4
```
Настоящий перевод фокуса между двумя объектами: два слоя (передний/задний), один размывается, другой проясняется. ⏱ ≈ 14 с (можно быстрее через `xfade` двух заранее размытых версий).

### L-15 Каустика — отражённый свет воды на стене/лице

Слой колец/ряби (L-10 без плиты) → `lut` для жёстких светлых линий → `blend=all_mode=screen`, прозрачность 0.15–0.25, по маске стены. Фирменный признак интерьеров Низов (дом Нан) и бортов кораблей.

### L-16 Поднимающаяся вода / маска уровня (Sc 1, изображение 2; E10)

```bash
ffmpeg -y -i PLATE.mp4 -f lavfi -i "color=0x10203a@0.85:s=1920x1080:r=24:d=$D,format=rgba" -filter_complex \
 "[0][1]overlay=x=0:y='H-(H*0.15+H*0.25*t/$D)':shortest=1,format=yuv420p" -c:v libx264 -crf 18 OUT.mp4
```
- Вместо однотонного слоя — плита воды (с L-10) с мягким краем (`gblur` по альфе) и полосой пены на кромке.
- Лестница приливных отметок на косяке: вода проходит отметки одну за другой, последняя — выше всех. Все слои Sc 1 хранить как именованные ассеты для E10 (production notes §8).
- ⏱ ≈ 1 с.

### L-17 Проявление по маске (пазы Шпиля загораются виток за витком; тинты на карте)

```bash
ffmpeg -y -i PLATE.mp4 -f lavfi -i "color=0x9fd8ff:s=1920x1080:r=24:d=$D,format=rgba,geq=r='r(X,Y)':g='g(X,Y)':b='b(X,Y)':a='if(gt(Y,H*(1-T/$D))*lt(mod(X+Y*0.5,120),10),220,0)'" \
 -filter_complex "[1]gblur=sigma=4[g];[0][g]overlay=shortest=1,format=yuv420p" -c:v libx264 -crf 18 OUT.mp4
```
- В рабочей версии маска — не формула, а **нарисованная маска пазов** (edit-запрос: `same image, only the spiral grooves painted pure white, everything else pure black`, $0.04) + порог, идущий снизу вверх. Свечение — два слоя: резкий и размытый (`gblur=sigma=20`).
- Тинты на карте (Sc 7, Sc 12): плашка цвета яруса по маске района + `fade=t=in:alpha=1` на нужной секунде. Подписи — `drawtext` в монтаже.
- ⏱ ≈ 22 с (`geq`). С готовой маской-PNG — 2–3 с.

### L-19 Переходы: наплыв и склейка по форме

```bash
ffmpeg -y -i A.mp4 -i B.mp4 -filter_complex "[0][1]xfade=transition=fade:duration=1:offset=3,format=yuv420p" -c:v libx264 -crf 18 OUT.mp4
```
- Склейка по форме (Sc 1→2: фонарь на чёрной воде → солнце на мокром иле; Sc 4→5: камень → тканая башня) — прямая склейка или наплыв 6–12 кадров; кадры совмещаются по объекту заранее, при генерации второго кадра edit-ом от первого.
- `xfade` знает и `wipeup`, `circleopen`, `fadeblack` — но в саге используем только `fade` и `fadeblack`.

### L-20 Падающая капля / мелкий предмет по траектории (Sc 16: капля чернил)

```bash
ffmpeg -y -i PLATE.mp4 -f lavfi -i "color=black@0:s=12x18:r=24:d=$D,format=rgba,geq=r=10:g=10:b=20:a='if(lt(hypot(X-6\,(Y-9)*0.7)\,6)\,255\,0)'" \
```

### L-21 Стоп-кадр с жизнью

«Замороженный» зал после падения (Sc 12), сорок перьев в воздухе (Sc 16): плита + L-07 (пыль) + L-01 (наезд 3%) + одна живая деталь (капля L-20, или одно движущееся перо — L-12 из двух рисунков). Самый дешёвый «иконический» кадр.

## 4. Сборка сложного кадра (порядок слоёв)

1. Плита (или петля L-13) →
2. движение камеры (L-01…L-05) **по плите и слоям вместе** (иначе эффекты «прилипают» к экрану) — для этого эффекты-«в мире» (кольца, каустика, свет фонаря) накладываются **до** движения камеры, на плиту увеличенного размера;
3. эффекты «в воздухе» (дождь, пыль, туман) — **после** движения камеры, со своим медленным дрейфом;
4. цвет и свет кадра (мерцание L-09, общее затемнение);
5. зерно (`noise=alls=4:allf=t`) — одинаковое на всех кадрах серии, в самом конце, чтобы LA и сгенерированные клипы выглядели одной плёнкой.

Каждый собранный кадр описывается в шот-листе строкой приёма: `LA: L-04 + L-06(2 слоя) + L-09, push 0.05`. Скрипт сборки по этой строке — предложение IT-инженеру (`pipeline/la.py`).

## 5. Производительность

- Самые медленные — `geq` (L-10, L-11, L-17): 3–6× дольше реального времени в 1080p. Считать карты один раз в половинном разрешении и переиспользовать.
- Оценка рендера LA-части пилота (~18 мин, ~300 кадров) на CPU: 1–3 часа в 1080p; аниматик в 720p — в 2–3 раза быстрее. Бесплатно.
